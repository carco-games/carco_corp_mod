# CarcoCorp Mod For Dusklight

## Hyrule has a new investor...

Give your Rupees more meaning with this brand new business opportunity in Dusklight!

### Features
1. Configurable paywalls for many of Link's items, abilities, and even game sounds!
2. A simple UI for purchasing CarcoCorp items!
3. Toggleable gameover fees!
4. Customizable price changing!
5. Customizable random returns!
